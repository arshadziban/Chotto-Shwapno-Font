# FontForge SVG Text Conversion Guide

To convert SVG text using FontForge, follow these steps:

1. **Install FontForge**: Download it from [https://fontforge.org/en-US/downloads/](https://fontforge.org/en-US/downloads/) and run the installer. It supports Windows, macOS, and Linux.

2. **Open the FontForge Console (Windows only)**: Run the following command in the terminal:

```bat
"C:\Program Files (x86)\FontForgeBuilds\fontforge-console.bat"
```

3. **Run the Python Script to Fix SVG Text**: Use the console to execute your script:

```bat
ffpython import_svg.py
```
